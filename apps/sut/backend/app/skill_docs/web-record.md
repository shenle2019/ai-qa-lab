# shenle-web-record

> 分组：**录制采集**　来源：`.claude/skills/web-record`

## 它是什么

打开网页，人工点 SNAP 抓当前视口与元素结构，按批次落盘。

技能自带的触发描述：

> 通过 Playwright（Chromium）录制网页的技能。当用户想要录制、抓取、截图保存某个网页的 UI（截图 + DOM/a11y 快照），并保存到本地批次目录供后续 AI 分析时，使用本技能。典型触发词：「帮我录制」「截一下」「抓一下页面」「截图保存」「采集信息」「录一下后台」「截一下首页」。技能会依次完成：环

## 核心功能

- 按批次组织快照：一批一个目录，便于回放和比对
- 同时保存截图与元素结构（可点区域、文本、层级）
- 支持交互式多步操作，每步都能单独快照

## 怎么用

```bash
shenle-web-record record https://example.com
浏览器打开后逐屏点 SNAP，完成后关闭窗口
```

## 产物与判读

`snapshots/<batch>/` 下每步一份截图 + 一份结构文件

## 常见失败模式

元素定位重复、视口过小导致目标被裁掉
