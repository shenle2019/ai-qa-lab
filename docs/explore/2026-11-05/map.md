# 系统地图（第一阶段：只看不点）

入口：https://ai-qa-lab-production.up.railway.app/ui/#/
入口页：仪表盘。左侧固定导航，顶部标题 + 「刷新状态」。全站 SPA，hash 路由。

## 顶层入口

| 路由 | 模块 | 这里大概能干什么 | 首屏关键入口 |
|---|---|---|---|
| `#/` | 仪表盘 | 看工单总量/状态分布；知识库快问；最近 6 条工单 | 刷新、查询、查看全部 |
| `#/tickets` | 工单管理 | 工单列表、搜索、状态/优先级筛选、行内改状态、新建/编辑/删除 | + 新建工单、编辑、删除 |
| `#/workbench` | API 工作台 | 请求构建、环境变量、发送、断言、集合批量运行、历史 | 发送、运行全部、保存到集合 |
| `#/knowledge` | 知识库问答 | 基于工单/内置知识做词法检索问答 | 提交问题、预设问题、Top K |
| `#/platform` | 测试平台 | 项目→用例→计划→执行→缺陷的闭环（单页五段） | 新建项目/用例/计划/缺陷、加载演示数据、执行、查看报告 |
| `#/models` | 模型中心 | 注册 OpenAI 兼容模型、连通性测试、调用记录 | 保存模型、测试、启停 |
| `#/testcases` | 测试用例 | 196 条用例目录，按状态/类别/关键字筛选 | 搜索、状态/类别筛选、完整报告 |
| `#/methodology` | 方法论 | 8 模块选型说明与对外链接 | 学习手册、GitHub 仓库 |
| `#/report` | 项目报告 | 项目里程碑报告、学习手册入口 | 学习手册、历史报告归档 |
| `#/portfolio` | 模块验收 | 各模块复刻说明、验收报告、OpenAPI 文档 | 打开报告、OpenAPI 文档、GitHub |
| `#/login` | 访问密钥 | 把 APP_API_KEY 存进浏览器 localStorage | 保存、清除 |

## 核心流程（必逛清单）

1. 工单：列表 → 搜索/筛选 → 新建 → 编辑 → 删除
2. 测试平台：项目 → 用例（手工/AI 生成）→ 审核 → 计划 → 执行 → 查看报告 → 缺陷
3. API 工作台：选集合请求 → 发送 → 看响应/断言 → 运行全部
4. 知识库：提问 → 看回答与来源
5. 模型中心：注册 → 测试连通性 → 看调用记录
6. 测试用例目录：筛选 → 打开完整报告
