# v4 · 明亮主题（黄绿白）+ 收尾三项 · 2026-11-06

这一轮做两件事：把深色蓝紫换成黄绿白的明亮配色，再把交接文档里挂着的几件事一次性收掉。

## 一、主题重做

原来的深色底（`--bg: #070b14`、青色 accent `#38bdf8`）整体换成暖白 + 黄绿：

| 层级 | 值 | 说明 |
| --- | --- | --- |
| 画布 | `#f4f7ea` | 暖白偏黄绿，铺一层极淡的点阵和两处光晕 |
| 卡片 | `#ffffff` | 纯白 + 1px 发丝线 + 轻阴影，和画布拉开层次 |
| 侧栏 | `#eef4dd` | 浅黄绿，和内容区形成左右分区 |
| 主色 | `#6f9c1f` | 橄榄绿，主按钮用它，白字对比 4.7:1 |
| 辅色 | `#a8cc4a` | 黄绿，用于渐变、色条、hover |
| 高亮 | `#b8860b` / `#fdf3d7` | 琥珀黄，用于待审、警告 |
| 正文 | `#1e2414` | 近黑的橄榄色，避免纯黑发硬 |

背景图不是位图，是 CSS 叠出来的：一层暖白底 + 左上黄绿光晕 + 右上米黄光晕 + 22px 点阵，`background-attachment: fixed`，滚动时不动。

### 顺手要改的两处

1. **HTTP 方法标签**：组件里写死了深色底的浅色字（`rgba(56,189,248,.16)` + `#7dd3fc`），在浅色下几乎看不见。在 `theme.css` 里用 `.method.m-get` 等选择器配 `!important` 压成浅底深字：GET 蓝、POST 绿、PATCH 黄、DELETE 红。
2. **40 处深色兜底**：16 个组件的 scoped style 里有 40 处 `rgba(4,8,16,·)` / `rgba(3,6,12,·)`。没有逐文件改（也避免再踩 PowerShell 改中文源码的编码坑），在 `theme.css` 末尾用元素选择器 + `!important` 统一接管输入框、模态遮罩、面板、气泡等。

## 二、收尾三项

### 1. 骨架屏

新增 `.skeleton` 与 `.skeleton-row`，接到三个数据量最大的列表：

| 页面 | 位置 |
| --- | --- |
| 需求管理 | 列表表格，6 行占位 |
| 功能测试 | 用例表格，6 行占位 |
| 知识库 | 文档区，5 条占位块 |

逻辑统一为「`loading && 列表为空` 显示骨架 → 否则显示数据 → 否则显示空态」，不再出现「加载中长得像没数据」。

### 2. 窄屏表格

1024px 下 `来源` 列的「手工」原本会折成两行。改成 `td { white-space: nowrap }`，让表格横向溢出，由 `.table-wrap` 的 `overflow-x: auto` 承接滚动。牺牲一点点横向滚动，换掉所有两行小字。

### 3. 旧版页面

侧栏原来有一个「旧版页面（V1）」折叠组，里面 10 条链接和新版功能重名、样式一样，用户分不清。现在：

- 侧栏只留一个入口「其他 → 工具与旧版入口」（`/tools`）。
- 新页面 `views/ToolsView.vue` 把 10 个旧页按「数据与看板 / 接口与用例 / 知识与协作」分组，每条给一句说明和路由，顶部提示「新流程请走侧栏对应页面」。
- 旧路由全部保留，只是不再占侧栏位置。

### 4. 线上 AI

`railway variables --set DEEPSEEK_API_KEY=…` 已配好，重新部署后 `POST /api/platform/models/1/test` 返回 `{"ok": true, "latency_ms": 1397}`，线上 AI 归因、需求分析、用例生成都能用了（之前是 502）。
