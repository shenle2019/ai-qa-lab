## 每个项目都有什么

每个项目都会补齐到下面这套结构（已存在的不重复创建）：

| 维度 | 每个项目的条目 |
| --- | --- |
| 需求 | 10 条（登录鉴权/订单管理/支付退款/搜索筛选/批量导出/权限控制/消息通知/审计日志/分页性能/数据看板） |
| 功能用例 | 10 条，状态分布在 草稿 / 待审核 / 已通过 |
| 测试计划 | 2 个（冒烟 / 回归），冒烟计划会真实执行 6 条用例 |
| 缺陷 | 3 条（超时、越权、性能） |
| 知识库 | 2 个，每个 5 个功能 × 4 篇文档 = 40 篇，自动分块 |
| 接口资产 | 1 份 OpenAPI，含 4 个真实平台接口 + 6 个业务接口 = 10 个接口 |
| 接口用例 | 10 条（4 条可执行 + 6 条参数校验草稿）+ 1 条跨接口场景 |
| UI 用例 | 10 条，覆盖概览/项目/需求/功能/知识库/接口/UI/环境/模块/成员页 |
| 环境 | 4 个（dev / test / staging / prod），带 Base URL 与变量 |
| 模块 | 4 个，带负责人 |
| 成员 | 4 个（测试/开发/产品/运维） |

## 复现方式

```powershell
# 本地（带 AI 分析与 UI 真跑）
.venv\Scripts\python.exe scripts\seed_dataset.py --base http://127.0.0.1:8000 --label local --ai --ai-limit 8 --ui-run --ui-limit 12

# 线上（写接口要带上 APP_API_KEY；生产没有 Chromium，跳过 UI 真跑）
.venv\Scripts\python.exe scripts\seed_dataset.py --base https://ai-qa-lab-production.up.railway.app --label remote --key <APP_API_KEY> --skip-plan-run

# 重新生成本文件
.venv\Scripts\python.exe scripts\dataset_report.py
```

脚本是幂等的：按项目名 / 用例标题 / 知识库名去重，重复执行只会补缺，不会翻倍。
