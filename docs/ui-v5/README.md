# v5 · 雾灰蓝底 + 靛蓝主色

v4 的黄绿主题偏暖、卡片和页面几乎同色，层次靠光晕撑。这一版换成冷一点的雾灰底 + 靛蓝主色，白只留给卡片和弹窗，层级靠「页面灰 → 侧栏更灰 → 卡片白」这三档拉开，不用渐变、不用重阴影。

## 二、和 v4 的差别

1. **去掉背景纹理**。v4 的暖白光晕和点阵全部删除，`body` 只有一个纯色 `#F4F6F8`——用户明确要求不要渐变。
2. **去掉装饰色条**。统计卡左侧的绿/黄/深绿三色条、页面标题下的渐变短线都删了。主色现在只出现在主按钮、链接、选中项、焦点环上。
3. **状态色统一浅底深字**。徽章边框改透明，靠底色区分；HTTP 方法标签用同一套语义色（GET 信息蓝 / POST 成功绿 / PATCH 警告黄 / DELETE 失败红）。
4. **顶栏从半透明毛玻璃改成纯白实底** + 1px 下边线。
5. **焦点环**改成 `rgba(79,107,237,.55)` 2px，输入框聚焦用 `rgba(79,107,237,.18)` 的 3px 外光。

## 四、没做

1. 1024px 下表头右侧仍要横向滚动（`td{white-space:nowrap}` 的代价）。
2. 旧版 10 个页面只继承新配色，没有重新设计。
3. 线上没装 Chromium，UI 自动化执行仍会失败（页面有提示）。
4. 接口自动化 / UI 自动化 / AI 调用日志三页还没接骨架屏。
