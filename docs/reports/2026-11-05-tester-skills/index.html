生成器缺陷

  • 函数名含连字符（如 test_platform_model-calls_get）→ Python 语法错误；
  • 路径参数是 <id> 占位符；
  • 请求体为空 {}，缺 title / name / project_id 等必填字段。

生产环境特殊规则已单独断言：/api/platform/plans/{id}/run 返回 410（生产禁用客户端上报），真实执行走 /execute（202）。
